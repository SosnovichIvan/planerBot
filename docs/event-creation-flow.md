# Вход в создание события

Контракт: администратор нажимает «Создать событие» в календаре либо `/event`
в Telegram → отдельное окно с формой → сохранение через существующий API →
событие и outbox одной транзакцией → публикация карточки worker в выбранном чате/теме.
Название, дата, время, место/адрес/карта, online-ссылка, описание и теги сохраняются
существующим контрактом EventInput. Новых таблиц, SQL-запросов и миграций нет.

Раньше форма раскрывалась ниже календаря, а `/event` без данных давал текстовый
шаблон. Теперь `/event` без данных даёт ссылку Main Mini App с параметром
`create_CHATID_TOPICID`, в личном диалоге — `create`. Команда с многострочным
шаблоном и импорт по тегу продолжают работать. Перед выдачей ссылки в группе
проверяются права пользователя и бота, ошибки сети закрывают этот путь.
Проверки членства и прав на самом API выполняются повторно: deep link не даёт прав.

Форма открывается только после загрузки прав чатов. Чужой/недоступный чат не
подменяется другим при автоматическом входе. Если исходная тема выключена,
нужно явно выбрать другую включённую тему. После закрытия или сохранения
start-параметр потреблён и смена чата не открывает форму заново.
Смена месяца/чата после сохранения не теряет сообщение об успешном сохранении.

Окно использует HTML dialog и существующие Tailwind-токены. Оно доступно сразу,
без прокрутки до низа календаря, имеет имя, начальный фокус на заголовке,
кнопки закрытия/отмены, Escape и нативную изоляцию фокуса. Фон не прокручивается.
Во время запроса закрытие запрещено. Несохранённые изменения требуют подтверждения
закрытия; при неизвестном результате запрос повторяется с тем же ключом и данными,
а закрытие предупреждает о необходимости сначала проверить календарь.

## Кнопка возле ввода Telegram

`setChatMenuButton` относится к личному диалогу бота, не к меню группы.
Права администратора не включают такую кнопку в группе. Команды `/calendar`
и `/event` и inline-кнопки в сообщениях — поддерживаемые пути запуска.
Меню вложений ограничено Telegram категорией рекламодателей.
Источники: https://core.telegram.org/bots/api#setchatmenubutton и
https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-attachment-menu.

## Поставка и приёмка

Рабочая ветка → PR develop → PR main → новый тег → деплой с резервной копией.
Production в рамках реализации не меняется. Backend и frontend обновляются
вместе: старый frontend не понимает новый create start_param и откроет календарь,
сохранение при этом остаётся совместимым. Перед выпуском — проверки тестов,
типов, lint, coverage, компиляции и Chromium (mock SDK/API); после выпуска —
реальный `/event` в группе/теме, создание администратором, проверка карточки
и отказ участнику в Telegram Android/iOS/Desktop.
