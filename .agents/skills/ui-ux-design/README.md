# UI/UX Design

Независимый skill для проектирования и ревью интерфейсов web, mobile и desktop.
Он использует локальный поисковый runtime и встроенные datasets для visual
direction, design systems, accessibility, interaction, responsive layout,
typography, colors, icons, motion и charts.

## Установка

Из корня Agent Skills Lab:

```bash
python3 install.py \
  --skill ui-ux-design \
  --agent codex \
  --project-dir /path/to/project \
  --yes
```

Выбери другой adapter или собственные `--skills-dir` и `--agent-file`, если
этого требует целевой agent CLI. Skill устанавливается целиком, требует только
Python 3.9+ и не зависит от `frontend-engineering`, `execution-state` или иных
skills.

## Использование отдельно

В задаче явно укажи skill и ожидаемый результат, например:

```text
Используй $ui-ux-design. Подготовь доступный visual direction и компактный
design contract для dashboard спортивного приложения. Код не изменяй.
```

## Совместное использование

Несколько skills устанавливаются независимо. Их объединяет prompt задачи,
который задаёт шаги и результат каждого шага:

```text
Шаг 1 — используй $ui-ux-design и сформируй design contract для экрана.
Шаг 2 — используй $frontend-engineering, реализуй подтверждённый contract на
текущем stack и проверь результат визуально. Не меняй решения шага 1 без
описания конфликта.
```

Сам skill не вызывает другие skills и не предполагает, что они установлены.
Будущий task composer сможет генерировать такой orchestration prompt, не меняя
пакеты навыков.

## Референс

При проектировании использован публичный репозиторий
[UI/UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
как функциональный и контентный референс. Из версии `2.13.0` по лицензии MIT
адаптированы поисковый runtime, datasets и часть справочных материалов.

Этот репозиторий не определяет архитектуру нашего skill целиком. Правила
установки, независимости, активации, взаимодействия с агентами и композиции с
другими skills разработаны в Agent Skills Lab. Точный reference commit и состав
заимствованных материалов зафиксированы в `upstream.json`, а лицензия и
атрибуция — в `LICENSE.upstream` и `THIRD_PARTY_NOTICES.md`.

## Что мы изменили и зачем

| Изменение | Зачем |
| --- | --- |
| Переименовали пакет в `ui-ux-design` и переписали `SKILL.md` | Дали skill понятную область ответственности без привязки к бренду или конкретному agent CLI. |
| Сделали установку полностью независимой | Skill можно использовать отдельно; он не требует `frontend-engineering`, `execution-state` или другой части проекта. |
| Вынесли объединение skills во внешний prompt | Одна задача может назначать разные skills разным шагам без скрытых вызовов и жёсткого dependency graph. |
| Заменили vendor-specific пути на поиск runtime относительно `SKILL.md` | Одинаковая установка работает в Codex, Claude Code, Gemini CLI и других совместимых окружениях. |
| Ограничили поиск минимальным режимом и одной уточняющей попыткой | Снижаем расход токенов и не перегружаем контекст полными datasets. |
| Установили приоритет требований пользователя и design system проекта | Локальные рекомендации не должны перезаписывать принятые продуктовые решения. |
| Запретили неявную сеть, установку пакетов и автоматическую запись | Skill остаётся предсказуемым и не расширяет разрешения исходной задачи. |
| Сделали сохранение design system явной операцией | `--persist` требует целевой каталог, а перезапись через `--force` — отдельного разрешения. |
| Исключили upstream CLI, gallery, templates, examples и distribution-файлы | В установленный skill попадает только runtime и материал, необходимый агенту в работе. |
| Добавили catalog metadata, agent metadata, versioning, provenance и тесты установки | Skill воспроизводимо устанавливается нашим installer и его происхождение можно проверить. |

Таким образом, исходный проект служит референсом и источником отдельных
MIT-компонентов, а адаптация под универсальную архитектуру Agent Skills Lab,
правила безопасной работы, независимая установка и интеграционные проверки —
наша реализация.

## Состав

- `SKILL.md` — правила применения и границы ответственности;
- `scripts/` — локальный BM25 search и генерация design-system рекомендаций;
- `data/` — searchable datasets и provenance;
- `references/` — подробные UX/accessibility и native/mobile правила;
- `upstream.json`, `THIRD_PARTY_NOTICES.md`, `LICENSE.upstream` — версия,
  атрибуция и лицензия адаптированного источника.

Текущая версия нашего skill — `0.2.0`.
